# Nintendo Streaminet

Nintendo Streaminet is a fictional streaming-service concept for movies, shows, and specials. The prototype combines HTML, CSS, JavaScript, and Python to present a polished landing page, interactive catalog filters, trailer modal, pricing cards, and a local development server.

## Features

- Responsive landing page for a family-friendly entertainment platform.
- Catalog cards for movies, shows, and specials with client-side filtering.
- Trailer preview modal and mobile navigation behavior powered by JavaScript.
- Python development server with no-cache headers for fast local iteration.

## Run locally

```bash
python3 server.py
```

Then open [http://localhost:8000](http://localhost:8000).
